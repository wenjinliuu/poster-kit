# 版式关卡（发布前看一次预览图）

内容关卡（标题回答主线、小标题是结论、数字有出处、好坏两面）在写 spec 之前按 `story.md` 第 4 节过一遍；这里只管版式。

逐条过，任何一条不过就改 spec 重新生成。只检查一轮。

1. **标题**：主句、大字各占一行（放不下会自动缩小，缩得明显变小就改短）；副句最多两行，不能只剩一两个字掉到第二行。
2. **不重叠**：文字没有压在分类小图标、徽章或其他文字上；背景物件只在标题区右侧，不挡正文。
3. **不截断**：公司名、数值没有被省略号截断；表格不溢出卡片。截断时缩短名称或减少每行公司数（`cols`）。
4. **分类数**：≤ 8 个，颜色没有重复；“其他”是灰色。
5. **数字**：单位、口径、日期都写了；百分比加起来合理（占比类 ≈ 100%）。
6. **logo**：看脚本输出的命中情况，缺失的公司是首字徽章而不是空白。
7. **长度**：普通海报 ≤ 约 2200px；深度速览（财报、重大事件）≤ 约 5000px。更长就拆成两张、做精简版或删减版块。
8. **页脚**：有来源或筛选口径、日期、免责声明。
9. **叙事**：大标题回答了一个问题；每个小标题是结论而不是栏目名；没有“示意图”和编造的数据；未披露的写了“未披露”；估算、预测都有标注（见 `recipes.md`）。
10. **图表**：瀑布图中间项浮在累计值上；区间、预估有说明；高亮只给一项，其余变灰。
11. **导出完整**：`scripts/test_export.py spec.json` 两个场景都是 ✓（PNG 高度 = 海报高 × 倍率，页脚可见）。模板导出必须走 `renderPoster()`（克隆到屏幕外再截图），不要改回直接截页面上缩放过的 `.poster`。
