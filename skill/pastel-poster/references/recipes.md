# 海报类型配方

先判断海报属于哪一类，再按对应配方收集信息、排版块。配方给的是默认骨架，内容不够就删块，不要为了凑块编数据。

## 通用叙事规则

1. **大标题回答一个问题**：主句可以是问题或事实（“Meta 这次融了多少钱？”），强调色大字给出答案和最关键的数字（“已锁定 **375** 亿美元”），副句补充口径或第二个数字。
2. **小标题就是结论**：不写“营收构成”，写“卖了什么：DRAM 占 **75%**”；不写“同业对比”，写“放到行业看：利润率第二”。读者只看小标题也能拿到要点。
3. **一个版块回答一个问题**：超预期多少？为什么？卖了什么？之后会怎样？同行怎样？市场怎么看？问题想不清楚的版块就删掉。
4. **口径写清楚**：
   - 确定性分层：已锁定 / 可选 / 计划，用瀑布图的 `state` 区分，不要把计划中的钱和已到账的钱加在一起当“融资额”。
   - 新闻里出现几个不同数字时，加一个“数字怎么来的”对账块（`points`，标签写数字）。
   - 没公布的写“未披露”，不要估一个数填上；估算、预测要标 E/F 或写“券商估算”。
   - 跨公司比较时标财季区间和会计准则；币种换算写汇率和日期。
5. **只画真实数据**：没有逐笔或逐日数据就不画走势线，用文字写“盘中最多跌 4–5%，收盘约 +1%”。不画“示意图”。
6. **长度**：普通海报 ≤ 2200px；深度速览（财报、重大事件）≤ 约 5000px，超过就拆成两张或做精简版（保留标题区、KPI 和前 3 个版块）。
7. **数字来源**：每个数字写进去之前都要能说出出处；页脚列来源和截至时间。

## 1. 财报速览（个股）

适用：某公司发布季报 / 年报。

信息收集清单：
- 公司公告：营收、营业利润、利润率、净利润、EPS，环比 / 同比；口径（GAAP/IFRS、是否初步）
- 一致预期：至少两家（LSEG、FactSet、彭博、本地媒体汇总），算出超 / 低于预期幅度
- 利润表里“为什么”：营业利润到净利润之间的大项（汇兑、投资损益、税）或收入的驱动拆分
- 分业务 / 分产品构成和量价（出货量、平均售价）
- 管理层指引和电话会要点（下季指引、资本开支、新产品、风险）
- 股东回报、现金和负债
- 同行最新一季的同口径指标（标财季区间）
- 行业周期指标（价格、库存、份额，标来源）
- 市场反应：股价（用 `price` 版块自动取行情画走势，事件日用 `events` 标出来，有目标价就加 `targets` 画喇叭口）、主要媒体标题、券商观点（目标价、评级）

骨架（`numbered: true`，`brand` 放公司 logo 和代码）：
`kpis`（营收 / 利润 / 利润率 / 净利润，带环比同比 `rows`）→ `group: 超预期多少`（`beat` + `waterfall`）→ `group: 卖了什么`（`mix`）→ `group: 展望与电话会要点`（`bars` 指引 + `points`）→ `row`（`kpis layout:list` 股东回报 | `bars` 需求来源）→ `group: 放到行业看`（`bars` 同行高亮自己 + `line` 份额）→ `group: 周期走到哪了`（`columns` 价格 + `line` 利润率）→ `points: 市场与观点`

示例：`examples/earnings-skhynix.json`

## 2. 公司事件速览（融资、并购、回购、重大合同）

适用：一件事，需要讲清“多少、从哪来、花到哪、影响什么”。

信息收集清单：
- 公告原文和 SEC / 交易所文件：金额、工具、价格、时间表、可选条款（绿鞋、ATM、可转换）
- 各家媒体报道的数字，逐个对上口径
- 参与方（认购方、对手方、承销商）
- 资金用途（公告原话）；公司的资本开支指引、现金流
- 相关业务背景（为什么现在做这件事）
- 当天及之后的股价表现（用文字写，或拿到真实行情再画线）、卖方观点、主要担忧

骨架：
`group: 几层口径一张图看懂`（`waterfall` 带 `state` 和 `brackets` + `points` 对账）→ `callout`（关键事实澄清）→ `group: 钱花在哪`（`callout` 未披露 + `kpis layout:list` 指引 + `bars` 赚 vs 花 + `callout` 缺口）→ `text`（背景）→ `kpis` / `bars` / `cards`（相关业务）→ `points: 市场怎么看`

示例：`examples/financing-meta.json`

## 3. 产业链 / 主题名单

适用：某主题受益股、产业链各环节代表公司。

信息收集清单：各环节作用一句话；每环节代表公司（市值、主营占比，拿不准的不放）；跨市场时代码写全。

骨架：`chain`（可加 `kpis` 或 `notes`）。示例：`examples/supply-chain.json`、`examples/global-semis.json`

## 4. 持仓 / 构成

适用：ETF 持仓、基金重仓、收入构成。

骨架：`holdings` → `table`（前几大的表现）→ `notes`。示例：`examples/etf-holdings.json`

## 5. 数据统计 / 资金流向

适用：资本开支、出货量、市场规模、资金从哪来到哪去。

骨架：`kpis` → `years` 或 `columns` → `ranking` / `bars` → `banner` → `flows` → `notes`。示例：`examples/capex-stats.json`

## 6. 行情 / 数据日报

适用：每日或每周的市场数据汇总（期权、资金、板块）。

信息收集清单：当日值和对比基准（20 日均值、常态、上周）；每个数字都写对比基准；方向判断给出可信度。

骨架：`kpis`（大盘、最强信号、最热环节）→ `deviation`（对比常态）→ `heatmap`（多日或多环节）→ `columns`（分时）→ `chips`（观察名单）→ `table` 或 `points`。示例：`examples/market-daily.json`

## 7. 研报 / 观点汇总

适用：投行研报日报、多家机构对同一公司的观点。

信息收集清单：机构、评级与变化、目标价与变化、发布日期、核心观点一句话、研报中的现价；同一公司多家观点并列，突出分歧。

骨架：`target`（目标价刻度，前 3 家焦点公司）→ `table`（其余公司一行一家）→ `points`（行业与宏观观点，标签写机构或主题）。重点公司超过 3 家时，只给前 3 家完整展示，其余压成表格，控制长度。

## 8. 知识科普 / 生活指南

适用：健康、生活方式、学习方法、产品使用、政策解读等“讲清楚一件事 + 告诉你怎么做”的海报。

信息收集清单：
- 权威来源（官方机构、学会指南、教科书、原始论文），每个说法都能指出出处；有争议的说法写清楚“有研究认为”
- 一个核心数字或结论放大标题（如“成年人每晚至少睡 7 小时”）
- 原理（为什么）→ 做法（怎么做）→ 误区（别怎么做）→ 什么情况要找专业人士
- 能量化的部分（比例、时长、剂量）单独拎出来做图

骨架：`cards`（3 个带图标的要点）→ `cycle` / `tree` / `pyramid`（原理或结构）→ `timeline` 或 `steps`（怎么做）→ `compare`（好习惯 vs 坏习惯）→ `quadrant`（先做哪个）→ `callout`（何时就医、免责声明）

示例：`examples/sleep-guide.json`

## 9. 通用数据报告

适用：调研报告、行业数据、城市 / 人口 / 消费统计、产品运营数据等。

信息收集清单：
- 数据来源、样本、统计口径和时间；不同来源的数字不混用
- 一个最重要的发现放大标题，其余发现每个配一张图
- 每张图先想清楚是哪种关系（排序、变化、占比、相关、分布、流向），按 `charts.md` 选图

骨架：`kpis`（3 个核心指标，带图标）→ 每个发现一个版块（结论写在小标题里），常用 `donut` / `stackbar` / `scatter` / `slope` / `treemap` / `funnel` / `sankey` / `sparks` → `notes` 或 `callout`（口径说明）

示例：`examples/city-life.json`（虚构数据，展示各类图表）

## 10. 事件始末 / 人物与机构介绍

适用：一件事的来龙去脉、一个人或组织的经历与成就。

骨架：`kpis`（关键数字）→ `timeline`（竖排，关键节点 `highlight`）→ `tree`（组织结构、关系）→ `points`（各方说法，标签写来源）→ `callout`（还不确定的地方）

## 11. 对比评测 / 选购建议

适用：两个或几个产品、方案、城市、学校的比较。

骨架：`compare`（两个对象逐项对比，`winner` 标胜出方）或 `radar`（3 个以内对象多维对比）→ `bars`（关键指标排序）→ `quadrant`（按两个维度分类推荐）→ `cards`（不同人群怎么选）
