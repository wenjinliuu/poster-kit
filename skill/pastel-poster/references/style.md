# 风格配方：雾彩·清透

## 一句话

白底干净，信息多彩：底色接近纯白，右上一个淡化的主题物件交代主题，颜色只出现在分类、数字和图表上。

## 画面

- 画布宽 1080px，内边距 76 / 72 / 52px，版块间距 30px。高度随内容。
- 背景：白色到 `#f7f8fc` 的纵向过渡，没有彩色色块、没有模糊。
- 背景物件：程序绘制的等距图形，用强调色的 95%/90%/84% 白混三面明暗，宽 620px，贴右上角出血放置，压在标题后面。选和主题最接近的：芯片 `chip`、光模块 `module`、服务器 `rack`、硬币堆 `coin`（资金、分红、ETF）、柱群 `globe`（统计、指数）。
- 卡片：白底、圆角 30px、1.5px 浅灰描边、无阴影；分组区块用分类色 94% 淡底、圆角 28px。

## 字体

- 中文：`Noto Sans SC` / 苹方，标题 900 字重。
- 数字与代码：`Plus Jakarta Sans` 800。
- 字号：主句 88px、强调大字 104px、副句 50px；版块标题 30px；正文 17–19px；公司代码 27px。

## 标志性手法

- 三层标题：黑 → 强调色 → 灰。
- 分类用彩色胶囊标题 + 同色淡底区块，右上角放同色小物件图标。
- 公司统一“圆形 logo + 粗体代码 + 灰色名称”。
- 大数字永远比说明文字醒目。

## 渐变规则

- 只用同色深浅：排行条从“主色混白 32%”到主色（左浅右深），重点柱从下浅到上深，合计横幅从“主色加 14% 黑”经主色到“主色混白 16%”。
- 只用在条、柱、横幅这类“量”的元素上；文字、分类胶囊、卡片底色不用渐变。
- 不跨色相（不做紫到粉、蓝到绿这类渐变）。

## 版本

默认只有“清透” `clear`：分区底 94% 淡色，卡片细描边、无阴影。新增风格时在模板的 `VERSIONS` 和 CSS 里各加一项，配方写进本文件。

## 禁用

- 彩色大背景、玻璃模糊（导出不支持）、渐变标题字、跨色相渐变。
- 土色、暗黄、发灰的颜色（见 `palette.md`）。
- 手画或仿画任何公司 logo；没取到就用首字徽章。
- 二维码、平台水印。
