# 风格配方：雾彩·清透

## 一句话

白底干净，信息多彩：底色接近纯白，右上一个淡化的主题物件交代主题，颜色只出现在分类、数字和图表上。

## 画面

- 画布宽 1080px，内边距 76 / 72 / 52px，版块间距 30px。高度随内容。
- 背景：白色到 `#f7f8fc` 的纵向过渡，没有彩色色块、没有模糊。
- 背景物件：程序绘制的等距图形，用强调色的 95%/90%/84% 白混三面明暗，宽 620px（高不超过 430px），贴右上角出血放置，压在标题后面。选和主题最接近的：

  | 物件 | 适合 |
  |---|---|
  | `chip` 芯片 | 半导体、算力、AI 硬件 |
  | `module` 光模块 | 光通信、网络、连接器 |
  | `rack` 服务器 | 数据中心、云、服务器 |
  | `wafer` 晶圆 | 晶圆制造、设备、存储 |
  | `db` 数据库 | 存储、数据、软件 |
  | `coin` 硬币堆 | 资金、融资、分红、ETF |
  | `globe` 柱群 | 统计、指数、行情日报 |
  | `battery` 电池 | 储能、电动车、电力 |
  | `building` 楼群 | 地产、银行、城市、基建 |
  | `robot` 机器人 | 机器人、具身智能、自动化 |

  都不合适时用 `parts` 自己拼：`"object": {"parts": [["box", x, y, z, 宽, 深, 高, "body"], ["cyl", x, y, z, 半径, 高, "core"]]}`。坐标 x 向右下、y 向左下、z 向上，单位约等于像素；色调 `body`（最淡）、`pin`、`core`（最深）。先写后面、下面的块（画家算法，后画的盖住先画的）。只用 3–8 个块拼出主题的轮廓（如汽车 = 车身 box + 车顶 box + 4 个 cyl 车轮），不要细节，不要文字。
- 卡片：白底、圆角 30px、1.5px 浅灰描边、无阴影；分组区块用分类色 94% 淡底、圆角 28px。

## 字体

- 中文：`Noto Sans SC` / 苹方，标题 900 字重。
- 数字与代码：`Plus Jakarta Sans` 800。
- 字号：主句 88px、强调大字 104px、副句 50px；版块标题 30px；正文 17–19px；公司代码 27px。

## 品牌头部与编号

- 个股、公司事件海报写 `brand`：左边放公司字标（官方字标优先，其次按品牌色重建的文字字标，见 `logos.md`），右边强调色代码和海报类型。
- **品牌色优先**：涉及某一家公司时，用它 logo 里的颜色做强调色（`brand.colors`，第一个是主色、第二个是辅色），标题大字、重点柱、高亮项都跟着品牌色走；其余分类色自动接 8 色里和品牌色不冲突的颜色。太浅的品牌色（黄、浅青）用作文字时自动加深。
- **该突破就突破**：主题色是默认，不是枷锁。涨跌用涨跌色，同行对比里别的公司用灰色，提到其他公司时带上它的 logo；产品、类别本身有约定俗成的颜色（如某品牌的产品线）也可以用 `tone` 写十六进制颜色。
- 深度速览写 `numbered: true`，卡片标题前加强调色圆形编号。

## 图表

- 只有一个系列需要突出时，其余用灰色（同行对比高亮自己、多条线高亮一条）；没有主次时才用分类色。
- 预估 / 预测用淡色柱或虚线，并在 `caption` 写明 E、F 的含义。
- 瀑布图必须是真瀑布：中间项浮在累计值上，用 `waterfall` 版块，不要用普通柱状图冒充。
- 确定性分层用实色 / 斜纹 / 虚线框三档，图例写清每档含义。
- 图表文字是绝对定位的 HTML，不写在 SVG 里（导出时 SVG 拿不到网页字体）。新增图表照这个做法。

## 标志性手法

- 三层标题：黑 → 强调色 → 灰。
- 分类用彩色胶囊标题 + 同色淡底区块，右上角放同色小物件图标。
- 公司统一“圆形 logo + 粗体代码 + 灰色名称”。圆形 logo 外圈是一道品牌色描边加一圈细白边（取 logo 时自动从图里提取品牌色，取得不准就在 `companies` 里写 `color`）；黑白 logo 配深灰细圈。整张海报想统一时用 `badge_ring: "category"` 或 `"accent"`。
- 大数字永远比说明文字醒目。

## 渐变规则

- 只用同色深浅：排行条从“主色混白 32%”到主色（左浅右深），重点柱从下浅到上深，合计横幅从“主色加 14% 黑”经主色到“主色混白 16%”。
- 只用在条、柱、横幅这类“量”的元素上；文字、分类胶囊、卡片底色不用渐变。
- 不跨色相（不做紫到粉、蓝到绿这类渐变）。

## 版本

默认只有“清透” `clear`：分区底 94% 淡色，卡片细描边、无阴影。新增风格时在模板的 `VERSIONS` 和 CSS 里各加一项，配方写进本文件。

## 禁用

- 彩色大背景、玻璃模糊（导出不支持）、渐变标题字、跨色相渐变。
- 土色、暗黄、发灰的颜色（见 `palette.md`）。
- 小 logo（列表、图表里的圆形徽章）手画或仿画；没取到就用首字徽章。头部的大字标可以按 `logos.md` 的规则用官方字标或文字重建。
- 二维码、平台水印。
- 任何 `box-shadow`（内阴影会变成实心色块，外圈阴影会盖住圆点和 logo）；描边一律用 `border`。
- 行内的 logo 徽章：放在 `display:flex` 的容器里（html2canvas 画不出行内元素里的徽章图片），图片尺寸用像素写死。
- `box-shadow: inset …`（内阴影描边）、`color-mix()`、`backdrop-filter`：导出用的 html2canvas 1.4.1 不支持，内阴影会导出成实心色块。描边一律用 `border`（用 padding 抵消多出的宽度），混色在 JS 里算成十六进制再写进样式。
- 导出时不要直接对页面里被 `scale()` 缩放、被 `.frame` 裁剪的海报截图：模板的 `renderPoster()` 会把海报克隆到屏幕外 1080 宽的临时容器再截，改导出逻辑时保留这一点，并跑 `scripts/test_export.py`。导出前还会把宽或高不足 2px 的渐变背景换成纯色（html2canvas 遇到 0 尺寸渐变会报 createPattern 错误，整张图失败），接近 0 的进度条可以放心用渐变。
